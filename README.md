# Dua-Azkar-App
Islamic Dua &amp; Azkar mobile app. Easy access to daily duas, morning/evening Azkar, and Quranic supplications. Built with Flutter. Clean UI for Muslims.An Islamic mobile app to help Muslims easily access daily Duas, Morning & Evening Azkar, and Quranic supplications.

**Features:**
* Daily Duas and Adhkar in Arabic with translation
* Morning & Evening Azkar section
* Clean, distraction-free UI
* Search and bookmark favorite duas
* Works offline
